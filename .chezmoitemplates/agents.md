## Conventions

- Dotfiles: chezmoi (`chezmoi cd` is the source repo). Before editing a file in `~`, check
  `chezmoi managed`: if it is managed, edit the source (`chezmoi edit <file>`) and `chezmoi apply`,
  or the next apply overwrites your change.
- Packages: `packages/Brewfile` (macOS), `packages/arch.txt` + `arch-<host>.txt` (Arch),
  `packages/windows.txt` (winget). Runtimes and dev CLIs: mise (`~/.config/mise/config.toml`),
  not `npm -g` or system packages.
- Shell: fish on macOS/Linux, PowerShell on Windows.
- Containers: rootless podman. `DOCKER_HOST` points at the podman socket; there is no Docker daemon.
- Repos are cloned under `{{ $f.projects_dir }}/<repo>`.
- Git: commits are SSH-signed. Never add AI attribution or `Co-Authored-By` trailers to commits or PRs.
- Secrets never go into git (no `.env`, tokens, kubeconfigs, `terraform.tfvars`).

## Live state: look, don't guess

This file only holds what rarely changes. For anything current, ask the machines:

- `tailscale status`: which devices exist and are online
- `kubectl get applications -n argocd`: app sync and health (`KUBECONFIG=~/.kube/config-k3s`)
- `kubectl get pods -A`, `kubectl -n <ns> logs deploy/<app>`
- `ssh <host> -- <cmd>` for another machine, `chezmoi diff` for dotfile drift

For homelab operations (debugging an app, adding a service, Terraform), use the `homelab` skill.
